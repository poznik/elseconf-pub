# ElseConf

Свой мессенджер: нативные клиенты для Windows, macOS, iPhone и Android с чатами, звонками и
конференциями на общем ядре.

Здесь лежат готовые сборки. Установщик клиента для Windows — в разделе
[Releases](https://github.com/poznik/elseconf-pub/releases/latest).

- Windows 10 20H1 и новее, x64. Права администратора не нужны.
- Обновление — тот же установщик поверх прежней версии, данные остаются.
- Без WebView2 Runtime не откроются встречи по ссылке и вход через SSO.
